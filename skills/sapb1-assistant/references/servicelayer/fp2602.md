# SAP Business One 10.0 FP 2602 Service Layer notes

This file contains Service Layer changes relevant to integration design, not a general FP 2602 release summary.

## 1. Webhooks arrive in FP 2602

SAP states that **Service Layer webhooks are supported as of SAP Business One 10.0 FP 2602**. They let an
external endpoint receive notifications for subscribed B1 events instead of polling continuously.

A new **Webhook Messenger Service** component handles delivery behind Service Layer.

Sources: `guide` (`Webhooks`), `fp2602-change` in `INDEX.md`.

## 2. Enable and subscribe

SAP's quick start says webhooks are disabled by default per company. Enabling uses the Service Layer company
administration API and the `EnableWebhook` setting.

Subscriptions are managed through the `EventSubscriptions` entity set. SAP documents ordinary CRUD methods
for subscriptions and a catalog operation for the available events.

The FP 2602 API change log adds, among other webhook-related members:

- `AdminInfo.EnableWebhook`.
- Entity types/entity sets for event subscriptions and event notifications.
- `EventSubscriptionsService_GetEventCatalog`.
- Bound subscription actions including `Handshake`, `Pause`, `Replay` and `Resume`.
- Webhook-related enums and configuration properties.

Sources: `guide` (`Quick Start`, `Event Subscription`), `fp2602-change` in `INDEX.md`.

## 3. Integration pattern

Use the webhook as the event signal. When the receiver needs authoritative current business-object state, fetch
that state with a normal Service Layer read. Receiver authentication, idempotency, durable queues and retry
policy are application architecture concerns and must be designed for the deployment.

The event-notification capability is SAP-documented; the receiver architecture is engineering practice.

## 4. Version guard

Do not generate webhook configuration for a B1 10.0 installation older than FP 2602 without an explicit
upgrade plan. For later service packs, check the sequential Service Layer API change logs instead of assuming
the FP 2602 surface is unchanged.
